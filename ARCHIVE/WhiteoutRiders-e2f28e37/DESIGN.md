# WHITEOUT / RIDERS
Inspiration image: e2f28e37

## Fantasy & verb
A heavy, powerful snowmobile floats over deep powder while dark conifers emerge from a blue-white storm. **Ride**: carve, lean, boost, jump, smash, tow. The detailed sled, crouched rider, twin ski tracks and curling powder are the visual center.

## Genre & loop
Third-person open-world snowmobile driving; no story gate. **Spot a beacon → choose a line → ride a job or stunt → bank credits → bolt on permanent upgrades → ride farther.** Start seated on a running sled; W works immediately. Nearby broad turns teach steering, a timber fence teaches destruction, and orange beacons invite jobs. A compass and icon map replace quest paragraphs.

## Playground
A continuous 2.4 km alpine basin: pine forest, logging camp, frozen lake, abandoned ski jumps, high pass and remote island. All visible terrain is reachable. Snowbanks launch the sled naturally. Fragile trees, fences and timber stacks break into pooled debris; tracks persist in a bounded ring buffer. A weather cycle alternates revealing distant ridges and close whiteout. Jobs cycle between delivery, rescue tow and timed trail runs. Each uses a start marker and a single destination, no dialogue. Rescue adds a physical trailing sled and reduces acceleration. Quick-play starts a random rescue run with a capable loaner, a 90-second clock, and instant retry.

## Permanent progression
Five linked branches, six tiers each (30 permanent purchases). Engine: torque → turbo → twin turbo → rally → glacier → summit (speed/boost, added exhausts). Track: paddle → long → studded → flex → deep → expedition (climbing and traction, visibly longer/wider track). Suspension: coil → long travel → rally → air → freeride → extreme (jump impulse/landing reward, exposed colored shocks). Utility: tow → winch → sealed hull → amphibious → expedition → storm (tow income, winch pull, lake glide, added rack/pontoons). Boost: bottle → recovery → dual → race → cryo → unlimited (capacity/recharge, glowing canisters). Each tier costs progressively more. Track 2 and utility 2 aid steep-pass access; utility 3 makes lake crossing faster. No prestige. Jobs and sustained drifts fund upgrades; stunts and smashing pay immediately. A garage overlay pauses riding and displays costs and six tier pips. Equipment changes update the sled immediately.

## Why keep riding?
Minute 1: immediate throttle, broad powder plumes, weighty drifting, smashable timber, first beacon reward. Minute 10: linked upgrades change speed, climbing and jumping; rescue handling and varied routes create choices. Minute 30: a visibly equipped expedition sled chains fast jobs, huge jumps and distant ridge lines; all five branches keep offering tangible gains.

## Feel & art budget
Blue-white fog, diffuse light, charcoal rider, layered snow-loaded pine silhouettes. Sculpted custom hull/windshield/ski meshes, articulated rider and suspension. World-space triplanar procedural snow grain on terrain; no stretched surface images. Speed-sensitive follow camera, spring lean, boost FOV, landing kick, streaking snowfall, layered synthesized engine/wind and impact tones. Big transient payout numbers, minimal short labels.

## Delivery & checks

Dev hooks injected only by a separate test server entry; production has no debug switch. Automated real-time three-minute low-quality drive exercises throttle, turns, boost, job completion, destruction and upgrade; screenshots at load, 30s, 180s and first upgrade.
